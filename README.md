# BSKTV WordPress Theme

商務 KTV／酒店店家資訊型 WordPress Theme。

## 核心模型

**一篇 WordPress 原生文章 = 一家店。**

不使用 WooCommerce，不建立獨立店家 CPT。文章標題、特色圖片與內容負責店家主體；城市、店型、特色為 Taxonomy；地址、營業時間、消費模式、聯絡方式與試算欄位為 Post Meta。

## 功能

- 商務 KTV／酒店專用首頁
- 店家文章詳細頁
- 城市／店家類型／特色分類
- 店家搜尋與分類導覽
- 編輯推薦／首頁精選
- 瀏覽次數
- 收藏（瀏覽器 LocalStorage）
- 相關店家
- Google Maps／電話／LINE／官方網站
- 消費資訊欄位
- 前端消費快速試算器
- Responsive Mobile UI
- LocalBusiness／Article 基礎 Schema
- WordPress Customizer 首頁文案
- PHP 8.2 Syntax CI

## 安裝

1. 將整個 `BSKTV` 資料夾放入 `wp-content/themes/`。
2. WordPress 後台啟用 BSKTV。
3. 建立城市、酒店類型與店家特色分類。
4. 新增文章；每篇文章就是一家店。
5. 上傳特色圖片並填寫「酒店資訊」與「推薦設定」。
6. 將「我的收藏」頁面套用「我的收藏」模板（Template Name: 我的收藏）。

## 內容建議

完整消費方案建議使用 WordPress Block Editor 的表格、標題、圖片與段落區塊撰寫。Theme 不限制文章內容格式。

> 實際消費、營業時間及店家服務內容應以店家最新公告為準。
